# Island Promo Factory

**Free toolkit that prepares the promo material for UEFN islands: thumbnails, logo, trailer, gameplay video and a ready-to-upload pack.**

> **Status: setting up.** This repository currently holds only the project's legal and community files. The code and the
> first release (v1.0.0) are published after the final tests. Watch the repository or check
> [Releases](https://github.com/mimmo-the-root/island-promo-factory/releases) to be notified.
