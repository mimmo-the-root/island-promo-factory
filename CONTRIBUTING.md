# Contributing

- One change at a time, test after each (`python tests/smoke_test.py`).
- Code and comments in English. Diagnostics go behind `PROMO_DEBUG=1`.
- Scripts must exit non-zero on failure and print a clear message; every stage must create or update its output.
- Never delete user files: move them to `final/_previous/` or a `_to_delete_*` folder.
- Do not add game/franchise artwork, fonts or badges you do not have the right to redistribute.
- Epic's specs change: if you update a size/limit, cite the Creator Portal page and date in the PR.
- By contributing you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Security problems: see [SECURITY.md](.github/SECURITY.md), never a public issue.
- Not affiliated with Epic Games: see [DISCLAIMER.md](DISCLAIMER.md).
