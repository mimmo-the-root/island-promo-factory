# Creator Portal media specs (checked October 2026)

Always verify on the Fortnite Creator Portal before uploading: these values change.

| Asset | Spec |
|---|---|
| Landscape image | 1920x1080 PNG/JPEG, < 5 MB. With title/text required; art-only version optional (no logo/text/CTA) |
| Portrait image | 1440x1920 (3:4), < 5 MB, optional |
| Logo | 1440x608 transparent PNG, < 3 MB |
| Lobby background | 2048x1024, < 10 MB |
| Trailer / gameplay video | 1920x1080 MP4/MKV/WEBM/MOV, < 400 MB, 10-40 s |
| In-game screenshots | up to 3, 1920x1080, < 5 MB |

Gameplay footage must be real and unedited, including the in-game UI. Epic composes art and logo at display time:
keep the bottom corners free (like % and New/Updated badges) and keep titles inside a 200 px top/bottom safe area.
The age-rating (ESRB) and "Developed in Fortnite" belong in videos only, not on thumbnails.
