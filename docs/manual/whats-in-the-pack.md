# What you get, slot by slot

Everything for the portal is in `Projects\my-map\promo_pack\`, numbered like the portal fields. `final\` only holds working files.

| File | Portal slot |
|---|---|
| `01_landscape_with_text` and `02_landscape_art_only` | Landscape thumbnail, with logo and art only |
| `03_portrait_with_text` and `04_portrait_art_only` | Portrait thumbnail, with logo and art only |
| `05_logo` | Island logo, transparent PNG |
| `06_lobby_background` | Lobby background (optional) |
| `07_gameplay` | Gameplay video: one continuous, unedited cut of your recording with the original audio |
| `08_trailer` | Trailer built from your real clips, with the end card and badges |
| `09_screenshot_1..3` | In-game screenshots |
| `UPLOAD_CHECKLIST.md` | What to tick before you upload |

Videos come twice: an MP4 and a ProRes MOV (`_prores.mov`). Epic asks for MOV ProRes, so upload that one.

> **Note** The gameplay slot is deliberately unedited: Epic wants real gameplay with the game UI. The polished montage, if you ask for it, lives in `promo_pack\social\` and is not for the portal.

`lightbox.png` puts everything on one board so you can check it in a glance.
