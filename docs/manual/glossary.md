# Glossary

- **Map:** one island, one folder in `Projects\`.
- **Kit:** the files for the Creator Portal in `promo_pack\`.
- **Stage:** one step of a run (images, music, trailer and so on).
- **Stage cache:** the record that lets a rerun skip stages whose inputs did not change.
- **Lightbox:** one board image showing every file of the pack.
- **ProRes:** the video format Epic asks for, delivered as a MOV file.
- **BT.709:** the colour standard the kit tags its videos with.
- **Qwen:** the AI model that paints the horizontal artwork (through ComfyUI).
- **ACE-Step:** the AI model that makes the music.
- **Licensed Music Box:** Epic's licensed music, required for Discover requests.
- **Replay:** Fortnite's recording feature, the best way to capture gameplay.
- **Safe area:** the top and bottom margin where titles must not go.
