Troubleshooting

Start with doctor.bat. Add --fix to let it repair the Claude kit, hooks and folders.

ProblemWhat to do
"ffmpeg not found"winget install Gyan.FFmpeg, then open a new terminal
"ComfyUI not reachable"Start it with start_comfyui.bat, or run with --no-qwen
Intake says BLOCKRead the line: it names the missing file or choice
A stage failedRead last_run_all.log, fix that one thing, run again; finished stages are cached
The console shows an old versionClose it and reopen it; after an update it restarts by itself
Thumbnail looks too similar to another mapRead final\similarity.json; change pose, framing or colours
Video colours look washed outMake sure you use the kit's own trailer and cuts: they carry BT.709 tags
Port 8791 is busySet PROMO_CONSOLE_PORT
Tip

Set PROMO_DEBUG=1 for extra diagnostic output.
