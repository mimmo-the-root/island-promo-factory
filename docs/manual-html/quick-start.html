Quick start

Fifteen minutes from a fresh install to a complete demo kit, without a GPU and without your own files.

  1. Install as described in Install (Python and ffmpeg are enough for the light setup).
  2. Run doctor.bat. It prints OK, WARN or FAIL for every part and the exact fix for anything missing.
  3. Run demo.bat. It draws a fictional map and builds the whole kit in about two minutes.
  4. Open Projects\demo\promo_pack\: the numbered files are what the portal asks for. Open lightbox.png to see them all on one board.
  5. Run dashboard.bat demo to open the live console in your browser (The console).
Tip

Using Claude Code? Open the kit folder and type /promo-pack instead of steps 3 to 5. Claude asks for your island code, title and files.

When the demo works, make your own map: Your first map.
