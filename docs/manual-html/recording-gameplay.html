Recording good gameplay

The portal wants real, unedited gameplay, and the kit cuts your recording, so the recording matters most.

Use Fortnite Replays

Record in the Replay feature so you control the camera:

  • Drone Free camera, so you can frame the action.
  • Set the Time of Day and turn the storm off.
  • High Quality FX on, controls hidden.
  • Record before you update the island, so the footage matches what players see.

What to record

  • Five minutes or more, 1920x1080, with the game UI visible.
  • Include the pre-game lobby: the portal asks for it.
  • Show the fun parts: the kit picks the busiest, sharpest moments for the trailer and screenshots.
Tip

Put the file in captures\gameplay\ and run run_all.bat my-map --redo-video --skip-images. The kit analyses it, picks moments and cuts the gameplay, the clips and the screenshots.
